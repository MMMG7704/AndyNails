# Sistema Andynails - Gestión de Salón de Uñas con Nombre Andy Nails

##  Descripción
Sistema de escritorio desarrollado en Java para la administración completa de un salón de uñas. Permite gestionar clientes, citas, servicios, inventario y pagos.

## Características del Sistema
 Login con usuarios y contraseñas
 Menú principal con acceso a todos los módulos
 Gestión completa de clientes (agregar, editar, eliminar, buscar)
 Sistema de citas con calendario
 Control de servicios y precios
 Registro de pagos
 Interfaz amigable y fácil de usar

Java 8+ 
NetBeans IDE  - entorno de desarrollo
MariaDB
GitLab
Java Swing

##Objetivo
Automatizar los procesos administrativos de un salón de uñas para mejorar la eficiencia y experiencia del cliente

## Ejecución
Abrir el proyecto en NetBeans y ejecutar la clase principal.
